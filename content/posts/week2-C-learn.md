## C语言学习梦开始的地方
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```    
在我的理解中```#include <stdio.h>```相当于告诉电脑在执行编程命令之前先去取一个工具包。

然后```int main(){}```是主函数，也就是电脑正式开始工作的开始。下面的```printf("Hello, World!\n");```也就是电脑工作的指令，意为输出“Hello, World!”这一串字符，其中\n则为换行的意思。 

最后基本在所有函数的最后都有```return 0;```，我的理解是这个是函数执行完毕之后的返还数据，如果是0则程序运行成功，非0则反之。！！！对了不要忘记在每行代码后加“;”啊！

## 变量的简单学习
其次了解了一些C语言中的数据类型如：整型（int）、长长整型（long long）、字符型（char）、浮点型（float）和双精度浮点型（double），并运用```type variable_name = value;```进行变量定义（type 表示变量的数据类型，variable_name 是变量的名称，value 是变量的初始值）

以及关于变量中的左值和右值，个人理解左值和指针很相似是数据存放的地址，而右值就是数据本身。

## 运算符（待深入学习）
运算符类型有点太多了有算术运算符、关系运算符、逻辑运算符、位运算符、赋值运算符、杂项运算符，其中位运算符、赋值运算符中有关位的部分还不是很清楚（等待深入学习），杂项运算符也是。

## 输入输出
有关这一部分仅仅简单学习了输入函数```scanf("%d", &a);```,其中&涉及指针意为将输入的数据存到原来a的地址。

以及输出函数```printf("Hello, World!\n");```，进行文本的输出。
